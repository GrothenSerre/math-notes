# Benjamin Andersson — Mathematics & Writing

A personal Quarto website for mathematics notes, theses, essays, blog posts
and downloadable documents.

- **Mathematics:** theses, lecture notes, exercises and new LaTeX-enabled notes.
- **Essays:** longer writing on philosophy, AI, religion and other topics.
- **Blog:** short notes and updates, with an RSS feed.
- **Documents:** a searchable archive of PDFs and other downloads.

See **[EDITING.md](EDITING.md)** for the short guide to adding posts and files.

## Build

Install [Quarto](https://quarto.org/docs/get-started/) and Python 3, then run:

```sh
quarto preview
```

GitHub Actions renders, checks and publishes changes to `main` with GitHub Pages.
Choose **GitHub Actions** under **Settings → Pages → Source** once.
The configured website address is https://GrothenSerre.github.io/math-notes/.
